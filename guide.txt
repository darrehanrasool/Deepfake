This guide provides simple, step-by-step instructions to set up, activate, and
run the DeepFake-AI project on Windows (university laptop / desktop with NVIDIA GPU).

--------------------------------------------------------------------------------
1. OPENING THE TERMINAL IN THE PROJECT FOLDER
--------------------------------------------------------------------------------
1. Open Windows File Explorer and navigate to your `Deep` project directory.
2. Click on the address bar at the top (where the folder path is shown).
3. Type `powershell` (or `cmd`) and press ENTER.
   A terminal window will open directly inside your project folder:
   C:\Users\YourName\Desktop\Deep>


--------------------------------------------------------------------------------
2. FIXING "RUNNING SCRIPTS IS DISABLED ON THIS SYSTEM" (POWERSHELL ERROR)
--------------------------------------------------------------------------------
If you try to activate your virtual environment in PowerShell and see this error:
--------------------------------------------------------------------------------
  File C:\...\venv\Scripts\Activate.ps1 cannot be loaded because running
  scripts is disabled on this system. (PSSecurityException)
--------------------------------------------------------------------------------

Windows blocks PowerShell scripts by default for security. Here are the 3 easy
ways to resolve it:

METHOD A (RECOMMENDED - PERMANENT FIX FOR YOUR USER ACCOUNT):
In your PowerShell window, run:
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
When prompted: Type 'Y' and press ENTER.
Now PowerShell will permanently allow activating virtual environments!

METHOD B (TEMPORARY 1-LINE BYPASS):
If you do not want to change policies permanently, launch PowerShell with bypass:
    powershell -ExecutionPolicy Bypass
    .\venv\Scripts\Activate.ps1

METHOD C (USE COMMAND PROMPT / CMD - NEVER BLOCKS SCRIPTS):
If you prefer not to touch PowerShell policies at all, just open Command Prompt:
    venv\Scripts\activate.bat
(Command Prompt never restricts .bat script execution!)


--------------------------------------------------------------------------------
3. CREATING THE VIRTUAL ENVIRONMENT (VENV) ON WINDOWS
--------------------------------------------------------------------------------
In your project folder (PowerShell or CMD), run:

    python -m venv venv

(Note: If `python` is not recognized, try `py -m venv venv`)
This creates a fresh, isolated `venv` folder containing your local Python runtime.


--------------------------------------------------------------------------------
4. ACTIVATING THE VIRTUAL ENVIRONMENT
--------------------------------------------------------------------------------
In PowerShell:
    .\venv\Scripts\Activate.ps1

In Command Prompt (CMD):
    venv\Scripts\activate.bat

SUCCESS CHECK:
Your prompt will now show `(venv)` at the beginning:
    (venv) PS C:\Users\YourName\Desktop\Deep>


--------------------------------------------------------------------------------
5. INSTALLING PYTORCH WITH NVIDIA CUDA ACCELERATION
--------------------------------------------------------------------------------
To ensure your university laptop's NVIDIA GPU is used (instead of slow CPU),
install the official CUDA-enabled PyTorch build:

For CUDA 12.1 / 12.4 (Modern RTX 3050/3060/3070/4050/4060/4070/4080/4090/T4):
    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

Install the required forensic dependencies:
    pip install opencv-python pandas scikit-learn matplotlib jupyterlab psutil

QUICK VERIFICATION:
Run this quick 1-line check to confirm PyTorch detects your GPU:
    python -c "import torch; print('CUDA Available:', torch.cuda.is_available(), '| GPU:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"

Output should display:
    CUDA Available: True | GPU: NVIDIA GeForce RTX ...


--------------------------------------------------------------------------------
6. LAUNCHING THE MASTER TRAINING NOTEBOOK
--------------------------------------------------------------------------------
1. With `(venv)` active in your terminal, launch Jupyter:
    jupyter lab
   (or `jupyter notebook`)

2. Your browser will automatically open.
3. In the left file explorer, open:
    notebooks / 01_master_multimodal_training.ipynb

4. Click the top menu:
    Kernel -> Restart Kernel and Run All Cells...


--------------------------------------------------------------------------------
7. WHAT THE NOTEBOOK DOES AUTOMATICALLY
--------------------------------------------------------------------------------
1. AUTOMATIC CUDA SELECTION & TELEMETRY (Cell 2):
   - Automatically detects NVIDIA CUDA, queries your GPU model (e.g. RTX 3060 Laptop),
     total VRAM, and enables FP16 Automatic Mixed Precision (AMP).
   - Reads host RAM (Total, Available, % used).
   - Queries GPU sensors (Core Temp, Fan Speed, GPU Core Load, Power Draw) via nvidia-smi.

2. DUAL BENCHMARK AUTO-DISCOVERY (Cell 3):
   - Searches your local drive for Google/Jigsaw DFD (22.5 GB / 3,431 videos) and
     Meta DFDC (1.86 GB / 400 videos + metadata.json).
   - Performs strict Actor-Isolated Group Partitioning (80% Train, 20% Val)
     with zero identity leakage between splits.
   - Computes dynamic inverse class weights to balance the 8.5:1 synthetic ratio.

3. SOTA MULTIMODAL ST2-SYNCNET TRAINING (Cells 4, 5, 6):
   - 8-frame temporal tubes with 2D Haar Wavelet 12-subband decomposition,
     spatial boundary seams, and Bi-directional GRU biological continuity.
   - Anti-overfitting regularizations: Label Smoothing (0.05), AdamW Weight Decay (1e-4),
     Dropout (0.4), Gradient Norm Clipping (1.0), and Cosine Annealing learning rate.

4. LIVE TERMINAL & CONSOLE PROGRESS:
   - Displays real-time progress on every batch with ASCII progress bar,
     loss, step speed, ETA, GPU VRAM allocation, and Host RAM %:
     [TRAIN] Epoch 01/10 | Batch 05/40 [██░░░░░░░░░░░░░░░░░░] 12.5% | Loss: 0.6319 (Avg: 0.6640) | VRAM: 1420MB | RAM: 28% | Step: 0.2s | ETA: 00m 07s

5. AUTOMATIC ACCIDENTAL INTERRUPTION RESUME:
   - Checkpoints are saved automatically:
     * `models/weights/latest_checkpoint.pt` (saved after every epoch and on user interrupt)
     * `models/weights/best_model.pt` (saved whenever validation ROC-AUC reaches a new peak)
     * `models/weights/training_metrics.csv` (CSV metrics history)
   - IF THE LAPTOP RUNS OUT OF BATTERY, RESTARTS, OR IS ACCIDENTALLY CLOSED:
     Simply launch Jupyter and run the notebook again!
     Cell 6 will automatically detect `latest_checkpoint.pt`, reload the model weights,
     optimizer state, learning rate, scheduler, and resume training right from that
     epoch without losing progress or restarting from Epoch 1!

6. PUBLICATION FIGURES (Cell 7):
   - Automatically saves high-resolution loss progression, validation ROC-AUC trajectories,
     and ROC curves to:
     `visualizations/real_multimodal_training_curves.png`
